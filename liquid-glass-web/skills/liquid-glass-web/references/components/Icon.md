# Icon

A small original stroke icon set on a 24px grid, 1.75 stroke, round caps, drawn in `currentColor`. A placeholder set: swap in the product's own symbols when they exist.

**Consumer provides:** `name` (one of `LG.Icon.names`), `label` (when the icon stands alone and means something; omit when a visible label sits beside it), `size`, `weight`.

- Icons in toolbars and tab bars are 22–24px; in rows 18px inside a 30px `accent` tile.
- One family per screen; never mix filled and stroke styles in a group.
