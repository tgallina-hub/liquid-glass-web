# Status

An inline status label: a glyph plus a word, colored `positive`, `warning` or `critical`. Color never carries the meaning alone.

**Consumer provides:** `tone` (`"positive"` `"warning"` `"critical"`), `children` (one or two words: "Approved", "Expires soon", "Denied").

- Use on `canvas` and `surface`. Over glass, write the status in `ink` and keep the glyph.
